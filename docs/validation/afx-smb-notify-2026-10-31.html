04结论适用范围

可以据此采用的能力

使用当前项目已有公开接口即可持续接收通知，无需修改库实现。监听单个文件时监控父目录并筛选相对路径；观察目录自身时间戳变化时，同样监听其父目录。

  • Added / Removed / Modified / Renamed
  • recursive(true / false) 与取消 token
  • 适用于变更提醒、目录刷新或触发同步扫描

本轮尚未覆盖

仅验证数据地址 192.168.9.101。未验证其他 LIF、断线恢复、通知溢出、高并发、ACL / 只读属性修改、其他协议触发的变化及节点故障。

  • 通知可能合并、溢出，不作为可靠审计日志
  • Modified 不包含内容差异、具体修改字段或操作者
  • 断线或溢出后，应用需要扫描、对账并重建监听
